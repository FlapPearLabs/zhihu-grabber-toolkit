## 1. 执行摘要

T11 对三个真实知乎语料规模带（~50 / ~200 / ~500）执行了端到端 dogfood：
抓取（real grab）→ 验收（verify-output）→ archive → popular-sample → top-percent（10%）→
hierarchical full digest（T9/T10）。

**关键结论（先行版）：**

1. **抓取与验收链路稳定**：4 个真实语料（47/79/183/318 条）全部 `valid=true` 验收通过；
   countMismatch 保持 DIAGNOSTIC_ONLY（19668080: 183/185、23933514: 318/324）。
2. **模型质量瓶颈（决定性发现）**：Qwen3 1.7B 对**长 canonical sourceId token**（`question-<qid>-answer-<aid>`）
   存在**截断回显**缺陷——模型把 `question-26421707-answer-153737013` 回显为 `question-26421707`
   （丢弃 `-answer-<aid>` 后缀），被 T6 控制器确定性拒绝（fail-closed，正确）。直接复现 5/5 次稳定失败；
   对照实验：短不透明 token（`src-0002`）回显 1/1 成功 → 缓解路径明确（短回显 token，未来 ticket）。
3. **影响（实测）**：全量 digest 要求 100% source coverage（不可跳过任何来源），任一来源 map fail-closed
   即阻断该语料的 digest。47 条语料 digest 完成（0 失败）；79 条 78/79 成功、1 源确定性失败 → 阻断；
   183 条（8 chunks 仅 2 map）、318 条（17 chunks 仅 2 map）均被阻断。失败率 ~1-2%/源，与内容长度/voteup
   无相关 → **规模越大越必然阻断**（实证而非外推）。
4. **hierarchical digest 实现本身工作正常**：47 条语料 flat+显式 hierarchy 双路径均产出
   `mode="digest"` final.json，verify 全 gate 通过；47 条规模（2 chunks）未触发聚合（ADAPTIVE 设计使然，
   默认 profile 参数 16/32000 下 <16 L1 节点不建层）。
5. **Issue #3 判定：保持 OPEN**。大型语料工作流的可用性/成本问题未被证明解决——模型质量阻断
   200+ 规模的全量 digest，hierarchy 的降本收益无法在真实 200/500 规模上完成对比验证。

## 5. 模型质量发现（MODEL_QUALITY_LIMITATION，非 PRODUCT_CODE_DEFECT）

### 5.1 两种确定性失败模式（均被 T6 控制器正确 fail-closed）

**模式 A — sourceId 截断回显（长 canonical token 回显不可靠）**

- 触发输入：canonical sourceId `question-26421707-answer-153737013`（正文为「占坑！一年过后再来答」占位回答）。
- 模型原始响应：`{"sourceId":"question-26421707","summary":"占坑！一年过后再来答。2017.03.26","stance":"neutral","confidence":0.95}`
  → **sourceId 截断**：丢弃 `-answer-153737013` 后缀。
- T6 控制器判定：`capability_isolation_unavailable: structured output references an unknown or mismatched source ID`
  → 该 chunk 不写 map，整 chunk fail-closed（**正确行为，零降级**）。
- 稳定性：26421707/153737013 直接复现 5/5 失败；23933514/65631563 2/2 失败；26546908/33355804 3/3 失败
  （该源在 digest run 中成功过一次 → 部分输入为高概率随机、部分为确定性）。
- 对照组（缓解路径证据）：同内容改用短 token `src-0002` → 模型回显 `"sourceId":"src-0002"` 1/1 成功。

**模式 B — confidence 越界（meta 数字误回显）**

- 触发输入：`question-19668080-answer-16713310`（803 chars / voteup 51，普通规模）。
- 模型输出 `confidence` 越界 [0,1]（T8 live smoke 已实证同类：模型把「赞同 N」meta 行数字抄进 confidence）。
- T6 控制器判定：`capability_isolation_unavailable: structured output confidence is invalid` → fail-closed。
- 稳定性：2/2 失败（有界重试）。

### 5.2 分类

| 项 | 判定 |
|---|---|
| 类型 | **MODEL_QUALITY_LIMITATION**（1.7B 长 token 回显截断 + meta 数字回显进 confidence） |
| 产品代码 | **无缺陷**——controller fail-closed、sourceId 契约、confidence 契约、coverage gate 全部按批准合同工作 |
| 违反规则？ | 否。未 clamp/强转/弱化验证/删断言/换 runtime/接受畸形输出 |
| 重试语义 | 已用批准 resume 语义（map 幂等重跑）有界重试（每源 ≤2-3 次）；不发明无限重试 |
| 失败率实证 | 47 源 0 失败（完成）；79 源 1 失败；183 源 1 失败；318 源 1 失败 → **~1-2%/源**，与长度/voteup 无相关 |
| 阻断判定 | **阻断可信跨规模比较**（200+ 规模几乎必然出现 ≥1 失败源 → full-coverage digest 无法完成；实测 183/318 均被阻断） |

### 5.3 对 #3 的意义

Issue #3 的「大型语料全量合成成本问题」在**模型质量层面**遇到真实天花板：即便 hierarchy 实现了
`claims -98.7%（synthetic 538 源）`的降本结构，Qwen3 1.7B 的 per-source 映射失败率也使 200+ 规模
无法可靠产出 full-coverage digest。**#3 保持 OPEN**，并记录本证据。
